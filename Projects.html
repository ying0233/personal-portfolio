My projects

Water Apps Project

This project is about developing a Java-Based and HTML interactive learning application using Visual Studio Code. The application provides reading materials in text form to help users learn and understand different topics. After that, users can answer quizzes to test their knowledge and earn marks. The apps also have leaderboard where users can view their rankings and system stores user information.

Tetris(Computer Graphics)

We are developing a Tetris game use c++ language. Players need to arrange falling blocks to complete lines and earn points. The game also includes sound effect to make it fun. A special feature is added where a tree will appears every time the player reaches 100 points.

Sarawak SHAA Database

This project focuses on developing a database system using XAMPP to ensure that all data is properly organised and stored according to specific categories. We also created a website that allows user to view existing data and newly added records easily.

ART Kuching (Mobile Application)

This project is about creating a mobile application using figma for the ART system in Kuching. The application helps users check ART station locations, find interesting places and choose routes using an interaction map. It is made to help users plan their tips and make travelling around Kuching easier.

Hiking map

This project is about creating a hiking map using Roblox Studio. The map allows players to explore different hiking areas and enjoy an outdoor adventure.
